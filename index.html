01 — About

A backend-leaning full-stack developer

I'm a Java & Web Developer comfortable across the entire software development lifecycle — from architecting secure RESTful APIs with Spring Boot and designing relational schemas, to crafting responsive, high-performance frontends.

Most of my depth sits on the backend: Spring Boot, Spring Security, JWT auth, role-based access control, Spring Data JPA and clean layered architecture. On the frontend I work with React, modern JavaScript and Tailwind to build interfaces that feel fast and stay maintainable.
